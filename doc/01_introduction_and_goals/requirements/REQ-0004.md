# REQ-0004: Das System verwaltet Produktmedien als Verweise auf den Objektspeicher

## Lizenzseite
Open-Source-Backend (`/app/koalixcrm`)

## Quelle
ADR-0003 (Produkt-Katalog-Backbone), ADR-0002 (Admin-UI-Framework: django-storages + S3 Presigned URLs)

## Why
Produktbilder, Datenblätter und Zertifikate müssen dem Frontend zugänglich sein, ohne dass
Binärdaten durch das Django-Backend gestreamt werden. Die Entscheidung in ADR-0002, `django-filebrowser`
durch `django-storages` und S3-Presigned-URLs zu ersetzen, ist der bindende Mechanismus für alle
Medienzugriffe.

## Beschreibung
`ProductMedia` (workspace-scoped) verwaltet Bilder, Datenblätter und Zertifikate als Verweise auf
S3/MinIO-Objektspeicher-Objekte. Das Backend speichert ausschließlich den Objektschlüssel und
Metadaten; der Dateitransfer erfolgt über Presigned-URLs. Workspace-scoped Entitäten erben den
`WorkspaceScopedModel`-Mechanismus: "Tenant-owned data inherits `WorkspaceScopedModel` and is
filtered by `request.active_workspace`" (ADR-0001).

## Acceptance Criteria

### AC-1: Datenstruktur
- [ ] `ProductMedia` trägt einen FK auf `Product`, einen `media_type`-Enum (`image`, `datasheet`, `certificate`), einen Objektschlüssel (S3-Key), eine `sort_order`-Ganzzahl und optionale `alt_text`-Angaben.
- [ ] Die Kombination `(product, object_key)` ist eindeutig; das System weist eine zweite Anlage mit demselben Schlüssel für dasselbe Produkt ab.

### AC-2: Presigned-URL-Lieferung
- [ ] Der DRF-Endpunkt liefert für jedes `ProductMedia`-Objekt eine zeitlich begrenzte Presigned-URL auf das S3/MinIO-Objekt.
- [ ] Das Backend speichert keine Binärdaten der Mediendatei in der relationalen Datenbank.
- [ ] Die Gültigkeitsdauer der Presigned-URL ist serverseitig konfigurierbar.

### AC-3: Workspace-Isolation
- [ ] Jede Datenbankabfrage auf `ProductMedia` filtert automatisch nach `workspace`.
- [ ] Ein automatisierter Test verifiziert, dass `ProductMedia`-Objekte aus Workspace A nicht in Abfragen aus Workspace B erscheinen.

### AC-4: Reihenfolge
- [ ] Die API liefert `ProductMedia`-Objekte eines Produkts in aufsteigender `sort_order`-Reihenfolge.

## Quality Attributes
- **Sicherheit**: Presigned-URLs laufen nach der konfigurierten Gültigkeitsdauer ab; abgelaufene URLs werden vom Objektspeicher abgewiesen.
- **Skalierung**: Das System unterstützt mindestens 20 `ProductMedia`-Objekte pro Produkt ohne Degradation der Produktdetail-Abfrage.

## Betroffene Komponenten
- Backend: `koalixcrm/products/models/product_media.py`, Presigned-URL-Generierung via `django-storages`, DRF-Serializer
- Frontend: Bildergalerie und Dokumentenbereich in Produktdetailansicht (über DRF-Endpunkte)
- Deployment: S3/MinIO-Bucket-Konfiguration (Presigned-URL-Berechtigung muss am Bucket aktiviert sein)

## Nicht im Scope dieser Anforderung
- Upload-UI und Drag-and-drop im Frontend (Gegenstand der Frontend-Anforderungen).
- CDN-Integration vor dem Objektspeicher.
- Virenprüfung hochgeladener Dateien.
